# 🎮 Simon Says Game

A simple and interactive **Simon Says memory game** built using **HTML, CSS, and JavaScript**.

The game generates a sequence of colored buttons. Your task is to remember the sequence and reproduce it by clicking the buttons in the correct order. With every successful round, the sequence becomes longer.


## ✨ Features

- 🎯 Simple and beginner-friendly Simon Says game
- 🔴 Four colored game buttons
- 🧠 Sequence-based memory gameplay
- 📈 Level increases after every successful round
- ✨ Visual flash effect for the computer-generated sequence
- 🟢 Visual feedback when the player clicks a button
- 💥 Game-over indication when the wrong button is pressed
- 🔄 Restart the game by pressing any key after Game Over
- 📱 Basic responsive viewport support

## 🕹️ How to Play

### 1. Start the Game
Open the game in your browser and press **any key** on your keyboard.

The game will start at **Level 1**.

### 2. Watch the Sequence
One colored button will flash.

Remember which button flashed.

### 3. Repeat the Sequence
Click the button that flashed.

If your answer is correct, the game moves to the next level and adds another color to the sequence.

For example:

```text
Level 1 → 🔴
Level 2 → 🔴 🟡
Level 3 → 🔴 🟡 🟢
Level 4 → 🔴 🟡 🟢 🟣
```

You must reproduce the **complete sequence from the beginning** on every level.

### 4. Game Over
If you click the wrong button, the game ends and your current level is shown as your score.

The screen briefly flashes red.

To play again, press **any key**.

## 🧩 Game Logic

The game uses two arrays:

- `gameSeq` — stores the sequence generated by the game.
- `userSeq` — stores the sequence entered by the player.

At each level:

1. The game generates a random color.
2. The new color is added to `gameSeq`.
3. The corresponding button flashes.
4. The player clicks the buttons in sequence.
5. Each click is compared with `gameSeq`.
6. If the sequence is correct, the next level starts.
7. If the sequence is incorrect, the game ends and the game state is reset.

## 💻 How to Run Locally

### Option 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open in your browser.
5. Press any key to start.

### Option 2 — Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Use **Live Server** if you have the Live Server extension installed.
4. Open the generated local URL in your browser.
5. Press any key to start the game.
